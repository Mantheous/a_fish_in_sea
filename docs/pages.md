# Pages
This documents the main navigation elements.

## Home
The main landing page. Quick actions that the user should see can show up here. I am considering just removing it and opting for the calendar as the main page as that is where the user goes for quick references anyways.

## Calendar
### Plan
This allows users to plan out their week/day and month in detail. The current usage is focused on being able to plan a week and follow the plan for a day.

### Report
This is a side by side view where you can see the events that were planned next to a report of what actually happened. I am considering moving this to it's own page. I almost always just end up viewing the current day.

## Goals
This allows users to plan out their goals from the bird eye view using a tree like structure. This is the same data as what you see in the calendar and finances, just from a different angle. Here you see how one goal leads to the completion of another.

## Finances
The ontology for finances doesn't exist yet. Do not worry too much about how this feature works
